air version=2
app customer_manager title="Customer Manager" subtitle="Instant CRM with search, validation, and status lifecycle" initial=overview

resource customers label=name

manage customers lifecycle=archive

overview

What AIR Can Do

AIR provides an integrated semantic compiler and runtime with nine fully verified capability layers.

🗄️

Semantic Schemas & Entities

Declare business resources with typed scalars (`text`, `email`, `phone`, `date`, `money`, `integer`), unique constraints, enum sets, and relational references.

resource products label=name field products.sku text required unique field products.price money currency=USD
🔄

State Machines & Guarded Transitions

Enforce role-based authority, separation of duty (preventing self-approval), mandatory comments, and append-only audit history streams below the UI layer.

process expenses state=status transition submit from=Draft to=Submitted by=owner transition approve from=Submitted to=Approved by=role:manager separate=submitter
🪟

UI Interaction Artifacts (Drawers & Menus)

Full drawer life-cycle supporting detail inspection, in-place edit hydration, context menus, focus trapping, dirty-state protection, and mobile sheet transformation.

manage customers lifecycle=archive # Inferred: collection table, mobile cards, right drawer, context menu
🔔

Notification Semantics & Center

Event rules and condition-transition edge triggers (`false → true`) with deduplication, user-scoped read states, unread badge count, desktop popover, and mobile sheet.

notify low_stock when="qty <= reorder_level & qty > 0" tone=warning notify out_of_stock when="qty <= 0" tone=danger
⏱️

Temporal Intervals & Schedules

First-class interval types with 10-scenario non-overlap matrix validation, blackout windows, duration algebra, and responsive calendar/agenda artifacts.

field booking_period interval start=start_at end=end_at invariant no_overlap none=reservations overlaps=booking_period
💰

First-Class Money Rates & Exact Algebra

Strongly-typed rates (`rate`) preventing dimensional errors, computed quotes via BigInt rational arithmetic, and symmetric half-away-from-zero rounding.

field hourly_rate rate currency=USD unit=h field quote money computed="booking_period.duration * hourly_rate"
📦

Relational Collections & Aggregates

Exact integer quantities, multi-resource line items, and declarative child aggregates (`sum`, `count`) without floating point drift.

field total money computed="subtotal - discount + tax" insight total_rev op=sum field=total
📱

Reproducible Benchmark Methodology

All measurements are generated automatically by tools/benchmark.mjs against checked-in source files in the repository.

  • LLM Tokenizer: Standard cl100k_base subword BPE tokenizer used identically across AIR and Conventional files.
  • Canonical AIR Tokens: Exact language token stream computed via the compiler's lexer (tokenizeLine in air.mjs).
  • Inclusion Policy: Only application-specific source files are measured. All platform/runtime code and third-party node_modules packages are strictly excluded.
  • Conventional Stack: React 19 + TypeScript + Tailwind CSS with standard state management and schemas.
  • Equivalence Tests: Both implementations execute against identical functional specifications to guarantee feature parity.
