# AIR v2 conformance corpus

This directory is the executable language contract shared by JavaScript and
Rust. Fixtures are intentionally small and domain-neutral.

- `valid/*.air` must compile. Adjacent `.expected.json` is canonical AIR
  Semantic IR generated by a conforming compiler and reviewed in source control.
- `invalid/*.air` must fail. Adjacent `.error.json` asserts stable `code`,
  `phase`, and `path`/source line; message prose is not compared.
- `canonical/*.pair.json` names sources that must produce structurally identical
  canonical IR.
- `execution/*.case.json` supplies source, seed data, principal/clock, actions,
  and exact semantic results. Programs contain no domain-specific runtime hook.

Run JavaScript conformance with `npm run conformance`. `--update` is a maintainer
operation that regenerates valid expected IR and execution outputs after an
intentional specification change. Rust integration tests consume the same files.

Fixture data is test input, not AIR application representation. Expected IR is
a compiler artifact and is not counted as AI-authored application source.
